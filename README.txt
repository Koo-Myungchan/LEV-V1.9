국소배기장치 설계 계산기 v1.8 (속도압 공식 반영 최종본)

① 필요환기량 → ② 이론적 원형 덕트 내경 → ③ 상용 규격 → ④ 실제 덕트속도 → ⑤ 속도압(mmH2O, Pa)

⑤ 속도압 계산: V(m/s)=4.043×√VP(mmH2O); VP(mmH2O)=(Vactual/4.043)^2; VP(Pa)=VP(mmH2O)×9.80665. 계수는 일반 공기 조건 근사값.

GitHub Pages: ZIP을 압축 해제하여 index.html, manifest.webmanifest, sw.js, icon.svg를 저장소 최상위에 업로드. Settings > Pages에서 main / (root) 설정.

상용 덕트 mm 규격은 실제 내경과 다를 수 있습니다. 다중 슬롯형 면적 정의도 별도 검증 필요.
